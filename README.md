# MATLAB Pendulum Phase Portrait

This repository contains a MATLAB script to compute and display the phase
portrait of a simple pendulum using Hamiltonian mechanics.

## Files

- `pendulum_phase.m` – generates the vector field and sample trajectories
  for the pendulum and plots the phase diagram.

## Usage

Run the script in MATLAB or Octave:

```matlab
pendulum_phase
```

A figure window will appear showing the Hamiltonian vector field of the
pendulum and several phase-space trajectories.
